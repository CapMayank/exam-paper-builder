## Open decisions for the owner

These were left as they are; none blocks the steps above.

**Print and export (from packages 1-2)**
- Word export of grouped exercises drops an item's OR, sub-parts and instruction, prints options only in MCQ sections, and uses the old option letters. Print and Word disagree there.
- The OMR sheet numbers every item, so a grouped exercise shifts OMR numbers against the printed paper.
- Diagram edits on the paper screen change the bank question, so every draft paper using it changes.
- A fill-in-the-blanks group can print "6. Each question carries 1 mark." as its question line when the section instruction is only a marks statement.
- Choosing English on content that looks Hindi flips back without a message (a stored "English" counts as "not chosen").
- Old "Do as directed." lines stored on questions still print; clearing the Printed instruction field removes them.

**Question modal (from package 3)**
- If an AI-generated question or a pasted batch is saved to the bank and then refused by the paper, pressing the button again saves a second copy to the bank. The Write tab already avoids this.
- AI chapter re-tagging still moves an OR question along with its main question, even on a class 1-8 paper where they were deliberately in different chapters.
- A few server messages still say "Alternate" and "primary"; the whole-paper AI audit still says "Bloom's Taxonomy".
- Class 9-12 blueprints with no stored type list still accept only the section's own type. The wider default list applies to classes 1-8 only.

## Decisions already taken (for reference)

- "Any k of n" questions print marks once, on the question line; every numbered question prints marks; OR pairs print marks once.
- No instruction prints unless typed. Exception: a non-empty section instruction that cannot be translated on a Hindi or Sanskrit paper prints the language default.
- The question modal opens on Write in every mode.
- OR same-chapter rule: guideline up to class 8, required from class 9. Marks stay fixed by the slot in every class.
- Class 1-8 sections with no stored type list offer the subject's usual forms; "Very short / One word" is offered at 1 mark and Grammar at 5 marks in language subjects.
- Workbench errors show as a toast only.
- Delegated agents should use the cheaper models (owner's request, 2026-11-13).
